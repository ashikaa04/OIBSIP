# Leonardo da Vinci — Tribute Page

A responsive tribute page built with **HTML5, CSS3 and vanilla JavaScript** for OIBSIP Web Development, Level 1, Task 2.

## Project structure

```text
WebDevelopment-Level1-Task2-TributePage/
├── index.html
├── style.css
├── script.js
├── README.md
└── images/
    └── IMAGE-SOURCE.md
```

## Run locally

1. Download or clone this project folder.
2. Open `index.html` in a modern browser.
3. For the best development workflow, open the folder in VS Code and use the **Live Server** extension.

No package installation or build step is required.

## Features

- Editorial-style hero section with a prominent historical portrait.
- Four original biography paragraphs.
- Chronological timeline of key life events.
- Three legacy cards covering art, science and invention.
- Distinct quote block with an attribution note.
- Dark charcoal, parchment and muted-gold colour palette.
- Playfair Display serif headings and DM Sans sans-serif body text.
- Responsive mobile navigation, scroll progress indicator and reveal-on-scroll effects.
- Keyboard skip link, semantic landmarks and reduced-motion support.

## Image credit and attribution note

The hero portrait is served from Wikimedia Commons using its Special:FilePath URL. It is the red-chalk drawing commonly called Leonardo's self-portrait. The identification is debated, so the page labels it as a *presumed* self-portrait rather than presenting the attribution as certain.

- File page: https://commons.wikimedia.org/wiki/File:Leonardo_da_Vinci_-_Self-Portrait_-_WGA12798.jpg
- The Commons file page provides the public-domain status and reuse information. Check the file page for the latest rights and attribution details before redistributing the image separately.
- The image loads from Wikimedia Commons, so an internet connection is required to display it.

## Customisation

- Update the content and source links in `index.html`.
- Change colours and typography in the `:root` variables at the top of `style.css`.
- Replace the hero image URL in `index.html` with another suitable Wikimedia Commons or Unsplash image if desired.
