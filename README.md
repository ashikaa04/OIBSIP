# Daylight — To-do Web App

**OIBSIP Web Development Internship · Task 3: To-Do Web App**

Daylight is a responsive, browser-based task manager built with HTML5, CSS3 and vanilla JavaScript. It helps users organise tasks into pending and completed lists.

## Features
- Add tasks using the input field or Enter key.
- Mark tasks complete and move them between lists.
- Edit pending task text inline (Enter to save, Escape to cancel).
- Delete tasks from either list.
- Live pending and completed task counts.
- Added and completed timestamps.
- Progress bar and friendly empty states.
- Persistent tasks using browser `localStorage`.
- Responsive layout for desktop, tablet and mobile.

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Browser `localStorage`

## Run Locally
1. Download or clone the repository.
2. Open this folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Add a task to get started.

Tasks are stored in the current browser and device. Clearing browser site data will remove saved tasks.
